# Sistema de gestión de expedientes para el Estudio de Ingenieria y Agrimensura Sancholuz

Trabajo práctico integrador de **Organización Empresarial**.

## Descripción del sistema

Este proyecto documenta el diseño de un sistema de información para el Estudio de Ingenieria y Agrimensura Sancholuz, una empresa familiar de la ciudad de La Plata.

El sistema apoya la gestión del ciclo completo de un expediente de mensura: registro del cliente y de la parcela, elaboración y aceptación del presupuesto, cobro de anticipo, relevamiento y dibujo del plano, presentación ante el organismo catastral, cobro del saldo, facturación y entrega de la documentación.

El repositorio aloja la documentación técnica del proyecto: estructura organizacional, modelo de datos y modelado de procesos.
